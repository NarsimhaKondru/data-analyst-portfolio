# data/

Put raw downloads here (e.g. `data/raw/cafe_sales_raw.csv`).

This folder is **git-ignored** on purpose — raw data files can be large and
should not go to GitHub. Instead, link to the original source in each
project README.

Rule: **never edit a raw file.** Always `Save As` a working copy inside the
project folder, so your cleaning steps stay reproducible.
