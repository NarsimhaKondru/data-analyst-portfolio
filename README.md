# Data Analyst Portfolio

**Name:** Narsimha Kondru
**Focus:** Entry-level Data Analyst roles (UK)

Five end-to-end projects covering the core skills listed in UK data analyst job adverts:
**Excel · SQL · Power BI · Python · A/B testing**

Each project answers one business question from start to finish:
`raw data → cleaning → analysis → visual → recommendation`
